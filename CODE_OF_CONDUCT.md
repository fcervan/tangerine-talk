# Código de Conduta

## Nosso compromisso

Este é um projeto comunitário e gratuito para aprender idiomas. Esperamos um
ambiente acolhedor para todas as pessoas, independentemente de experiência,
idioma nativo, identidade ou origem.

## Comportamentos esperados

- Seja respeitoso e específico ao criticar código.
- Assuma boa-fé; pergunte antes de presumir.
- Aceite que decisões de escopo são do mantenedor.
- Respeite a privacidade: não publique dados de outras pessoas.

## Comportamentos inaceitáveis

- Assédio, insulto, discriminação ou ataques pessoais.
- Publicar credenciais, dados pessoais ou conversas de terceiros.
- Spam, autopromoção agressiva ou pressão por funcionalidades pagas.

## Aplicação

Violações podem ser reportadas de forma privada ao mantenedor. As medidas vão de
advertência a remoção do projeto, conforme a gravidade.
